Входные данные

Формат: массив IMU-точек от ESP32. Каждая точка: {"t": миллисекунды_от_старта, "r": roll, "p": pitch, "y": yaw}
Или просто [{"t":0,"r":5.2,"p":-3.1,"y":12.0}, ...] Можно вставить данные из IMU Recorder или Simulator.
Загрузи JSON-файл из IMU Recorder или Simulator. Файл должен содержать массив IMU-точек или объект {"imuTimeSeries": [...]}.
Готовые примеры данных для тестирования разных сценариев. Генерируются прямо в браузере — устройство не нужно.
