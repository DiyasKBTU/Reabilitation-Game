📡 IMU Recorder

Подключается к ESP32-C3-IMU через BLE и записывает сырые данные. Экспорт в JSON → ML Debug.

Как использовать:
1. Включи устройство (ESP32-C3-IMU)
2. Нажми «Подключить BLE» — браузер покажет диалог выбора устройства
3. Нажми «⏺ Начать запись» — двигай кистью
4. Нажми «⏹ Стоп» — скачай JSON
5. Открой JSON в ML Debug для анализа

Важно: Нужен Chrome или Edge. Safari не поддерживает Web Bluetooth. Страница должна быть открыта на localhost или HTTPS.
